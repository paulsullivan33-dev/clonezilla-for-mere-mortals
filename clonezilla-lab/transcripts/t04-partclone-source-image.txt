The lab could not use a real disk, and would not have
pointed an imaging tool at one if it could. So it built
a filesystem inside an ordinary file — no loop device,
no mount — and imaged that. The files are invented and
generic: a workshop's field-notes folder.

$ find src-tree -type f | sort
src-tree/data/blob.bin           (1 MiB from /dev/urandom: incompressible)
src-tree/data/empty.txt          (0 bytes)
src-tree/data/measurements.csv   (invented readings)
src-tree/data/zeros.bin          (2 MiB of zeros: all too compressible)
src-tree/documents/manual.md     (an invented manual page)
src-tree/readme.txt

$ truncate -s 64M src.img
$ mkfs.ext4 -q -F -L FIELDNOTES -d src-tree src.img
(mkfs.ext4's -d fills the new filesystem from a directory:
 no mount, no loop device, the image is populated as made)

$ ls -l src.img ; du -h src.img
