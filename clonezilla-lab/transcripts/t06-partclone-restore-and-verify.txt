First attempt — kept because the failure is the lesson:

$ truncate -s 64M dst.img
$ partclone.ext4 -r -s src.pcl -o dst.img
Error exit
Partclone fail, please check /var/log/partclone.log !

$ tail /var/log/partclone.log
Starting to restore image (-) to device (dst2.img)
Output file 'dst2.img' already exists.
Use option --overwrite if you want to replace its content.
partclone.c,open_target,1684: open dst2.img error(17)
(partclone will not overwrite an existing target unless
 told to. On a real restore the target is a disk and the
 equivalent care is a typed confirmation, not a flag —
 but the refusal itself is the same instinct.)

With the flag:

$ partclone.ext4 -r -s src.pcl -O dst.img
Partclone successfully restored the image (src.pcl) to the device (dst.img)
Cloned successfully.

$ truncate -s 64M dst2.img
$ zstd -dc src.pcl.zst | partclone.ext4 -r -s - -O dst2.img
Partclone successfully restored the image (-) to the device (dst2.img)
Cloned successfully.
(the compressed image restored by piping the decompressor
 into partclone's standard input — the same plumbing
 Clonezilla uses, with zstd swapped for its own pipe)

$ e2fsck -fn dst.img
